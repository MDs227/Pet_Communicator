# 使用範例

## 範例 1：使用者完整輸入

**使用者輸入：**
```
我家三線鼠剛剛一直叫，幫我聽聽看
音檔：C:\Users\user\Desktop\hamster_recording.m4a
牠是不是被嚇到了？
```

**Claude 處理流程：**

1. 確認三項齊全：
   - 物種：三線鼠（鼠科 / 倉鼠類）✓
   - 音檔：`C:\Users\user\Desktop\hamster_recording.m4a` ✓
   - 提問：「牠是不是被嚇到了？」 ✓

2. 執行音訊分析：
```bash
python "C:\Users\user\.claude\skills\pet-communicator\scripts\analyze_audio.py" "C:\Users\user\Desktop\hamster_recording.m4a"
```

3. 假設腳本回傳：
```json
{
  "backend": "librosa",
  "duration_sec": 2.4,
  "rms_mean": 0.18,
  "rms_max": 0.42,
  "pitch_hz_mean": 4200,
  "pitch_hz_std": 320,
  "pitch_hz_range": 1500,
  "spectral_centroid_mean": 5800,
  "zero_crossing_rate_mean": 0.21,
  "tempo_bpm": null,
  "onset_count": 7,
  "voiced_ratio": 0.72,
  "notes": [
    "中等長度叫聲",
    "音量響亮",
    "高頻尖銳（約 4200 Hz）",
    "音高劇烈起伏",
    "高密度重複（約 7 聲）",
    "音色尖銳/明亮",
    "含明顯擦音/嘶聲成分"
  ]
}
```

4. 載入 `species_traits.md` 的【鼠類】段落 + `audio_emotion_mapping.md`

5. 產出：

```markdown
## 🎧 寵物溝通分析報告

**物種**：三線鼠（倉鼠類）
**你的提問**：牠是不是被嚇到了？
**音檔**：hamster_recording.m4a（2.4 秒）

---

### 1️⃣ 情緒推測

主要情緒：**強烈抗議或受驚嚇狀態**（信心度：High）

判斷依據：
- 高頻 4200 Hz + 音量響亮：在鼠類叫聲中，超出日常溝通的範圍，倉鼠日常多用超音波，可聽到的這個頻段通常代表負面狀態
- 高密度重複 7 聲 + 音高劇烈起伏：典型的「持續抗議」模式
- 含嘶聲成分（ZCR 0.21）：倉鼠是獨居動物，這類聲音常用來威嚇要求對方退開
- 物種知識補充：倉鼠被人類聽到叫聲本身就是警訊 —— 牠多數時候用超音波互動

可能的次要情緒：地盤被侵犯感 / 不舒服

---

### 2️⃣ 牠想說什麼（擬人化推測）

> 「不要再靠近我！我很不喜歡這樣，停下來！」

---

### 3️⃣ 建議行動

針對你的提問「牠是不是被嚇到了？」：

- ✅ **是的，這個叫聲強烈指向「被驚嚇或不適」狀態**，不像是放鬆時的聲音
- ✅ 立即停止當下正在進行的互動（抓取、清籠、移動籠子等）
- ✅ 觀察牠的姿態：是否站立後腿、毛炸開、咬籠子？這些都是配合驗證
- ✅ 給予 30–60 分鐘獨處時間恢復
- ⚠️ **若這聲音是在「沒有人接觸時」發出**，請檢查：籠內是否有其他鼠（倉鼠不能合籠）、是否有外來氣味（其他寵物）、籠子位置是否吵雜
- ⚠️ 若叫聲伴隨身體蜷縮、不吃不動，請考慮就醫

---

### 4️⃣ 音訊特徵摘要

| 特徵 | 數值 | 解讀 |
|------|------|------|
| 時長 | 2.4 秒 | 中等長度 |
| 平均音量 | 0.18 (RMS) | 響亮 |
| 平均音高 | 4200 Hz | 高頻尖銳 |
| 音高變化 | 320 Hz (std) | 劇烈起伏 |
| 聲音次數 | 7 次 | 高密度重複 |
| 節奏 | 無法估計 | — |

🔬 客觀觀察：中等長度叫聲；音量響亮；高頻尖銳（約 4200 Hz）；音高劇烈起伏；高密度重複（約 7 聲）；音色尖銳/明亮；含明顯擦音/嘶聲成分。
```

## 範例 2：使用者輸入不完整

**使用者輸入：**
```
我家貓在叫，幫我聽聽看
```

**Claude 應該回應：**

```
我可以幫你分析貓的叫聲！需要再補充以下資訊：

1. 📁 **音檔路徑**：請貼上音訊檔的完整路徑（支援 wav/mp3/m4a/ogg/flac）
2. ❓ **想問什麼**：例如「牠在生氣嗎？」「牠是不是不舒服？」「牠想要什麼？」

物種已知是貓 ✓，補上這兩項就可以開始分析。
```

不要在缺少資訊時自己編音訊特徵或亂猜情緒。

## 範例 3：非常見物種

**使用者輸入：**
```
這是我家蜜袋鼯的叫聲：D:\sounds\sugar_glider.wav
牠剛剛從睡袋裡跳出來叫的，是怎麼了？
```

**Claude 流程：**

1. 物種「蜜袋鼯」在 `species_traits.md` 的常見小寵物快速參考中有列出（蟋蟀聲=警報、Crabbing=防禦）
2. 執行音訊分析
3. 結合特徵 + 該物種知識
4. 在輸出中根據資料量決定信心度
