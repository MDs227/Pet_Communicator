## 🐱 貓（Cat / Felis catus）

### 主要叫聲類型

| 叫聲 | 典型特徵 | 常見情緒 |
|------|---------|---------|
| 喵（Meow）| 中頻 600–1500 Hz，0.3–1 秒，單次或重複 | 對人類的溝通請求（討食、開門、招呼） |
| 短促喵（Mew/Trill） | 中高頻、輕快、上揚 | 友善招呼、撒嬌 |
| 咕嚕（Purr）| 低頻 25–150 Hz，連續振動 | 多為滿足；極少數情況也出現於極度不適時的自我安撫 |
| 哈氣（Hiss）| 高 ZCR 噪音，0.5–2 秒 | 警告、威脅，請保持距離 |
| 低吼（Growl）| 低頻 < 200 Hz，拉長，漸強 | 攻擊前兆 / 護食護地盤 |
| 哀嚎（Yowl/Caterwaul）| 高音、拉長、起伏大 | 求偶、強烈不滿、認知障礙（高齡） |
| 顫鳴（Chirp / Chatter）| 高頻短促連發，下顎抖動 | 看見獵物時的興奮挫折 |
| 痛叫（Scream） | 極高頻、極響、瞬間爆發 | 突發劇痛或強烈恐懼 |

### 重要提醒
- 成貓對成貓很少喵喵叫，「喵」主要是貓對人類發展出的溝通方式
- 咕嚕在大部分情境是放鬆，但出現於陌生環境/疼痛時可能是自我安撫，需配合姿態判斷
- 哈氣 + 低吼組合 = 強烈警告，**不要繼續接近或抱起**

## 🐶 狗（Dog / Canis familiaris）

### 主要叫聲類型

| 叫聲 | 典型特徵 | 常見情緒 |
|------|---------|---------|
| 短吠（Bark, single）| 中頻 300–900 Hz，0.2 秒 | 警示、招呼、提醒 |
| 連續吠（Bark, repeated）| 高密度重複、中響亮 | 警戒、興奮、要求注意 |
| 低吼（Growl）| 低頻 < 200 Hz，拉長 | 警告、護食、玩耍時的假裝低吼（需配合肢體） |
| 嗚咽（Whine / Whimper）| 中高頻、起伏、拉長 | 焦慮、需求、興奮、不適 |
| 嚎叫（Howl）| 拉長、單頻或音高滑移 | 社交呼喚、分離焦慮、回應警報聲 |
| 尖叫（Yelp）| 短促高頻、單次 | 突發疼痛或驚嚇 |
| 喘息（Pant，含聲）| 高 ZCR、節律性 | 熱、興奮、焦慮（看上下文） |

### 重要提醒
- 連續吠 + 高頻 + 高密度，可能是分離焦慮，特別是飼主不在時錄到的
- 低吼漸強 + 高 ZCR + 牙齒外露聲 = 即將咬，**立即停止互動**
- 突發單次 yelp 一定要排除是否被踩到、夾到、或內部疼痛
- 嗚咽伴隨蜷縮姿態時，疼痛優先於情緒解讀

## 🐭 鼠類（Mouse / Rat / 倉鼠 / 龍貓 / 其他小型鼠科）

### 主要叫聲類型

注意：許多鼠類（特別是大鼠）的「快樂叫聲」是**超音波 22–50 kHz**，一般手機麥克風錄不到。可聽範圍內的叫聲多半是負面或防禦狀態。

| 叫聲 | 典型特徵 | 常見情緒 |
|------|---------|---------|
| 吱吱短叫（高頻短促） | > 3000 Hz，< 0.5 秒，重複 | 抗議、被打擾、輕度不滿、社交 |
| 持續尖叫 | 極高頻、拉長、響亮 | 疼痛、極度恐懼、被攻擊中 |
| 牙齒打顫 / 磨牙（Bruxing）| 短促節律噪音 | 倉鼠：壓力或威嚇；大鼠：放鬆滿足（需配合情境）|
| 嘶聲（Hissing）| 高 ZCR、拉長 | 倉鼠常見威嚇，要求被放下 |
| 咆哮（小型 growl）| 低頻、拉長 | 護食、護地盤 |

### 重要提醒
- **倉鼠**獨居動物，被同籠關押時的尖叫是嚴重警訊（可能正在被攻擊）
- **大鼠**社交性強，輕微吱叫常是互動，但持續尖叫需檢查健康
- **龍貓**：警報叫聲是中等響度的「ㄅㄧㄅㄧ」連續聲，意味牠感到威脅
- **天竺鼠**：「Wheek」高頻拉長是討食或興奮；「Rumble」低頻顫動是優勢宣示
- 鼠類叫聲被人類聽到本身就值得注意 —— 大部分日常互動牠們用超音波

## 🐰 兔（Rabbit）

兔通常不發聲，**有聲音時多半代表強烈情緒**。

| 叫聲 | 典型特徵 | 常見情緒 |
|------|---------|---------|
| 牙齒輕磨（Tooth purr） | 微弱節律 | 放鬆、滿足（類似貓咕嚕） |
| 牙齒重磨（Tooth grinding）| 較重、拉長 | 疼痛！需立即就醫 |
| 哼鳴（Honk / Grunt） | 低頻短促 | 求偶、興奮、輕度不滿 |
| 尖叫（Scream） | 極高頻、響亮、單次或短連 | **嚴重疼痛或極度恐懼**，緊急狀況 |
| 咆哮（Growl）| 低頻、拉長 | 警告、護地盤 |

### 重要提醒
- 兔尖叫是緊急訊號，**任何時候聽到都要立即檢查兔子狀況**
- 重磨牙與輕磨牙差異很大，重磨牙幾乎肯定是疼痛

## 🐦 鳥（Bird，通用 + 鸚鵡類）

### 主要叫聲類型

| 叫聲 | 典型特徵 | 常見情緒 |
|------|---------|---------|
| 鳴唱（Song）| 旋律性、複雜、拉長 | 社交、求偶、宣示地盤、開心 |
| 接觸叫（Contact call）| 中等響度、重複 | 「我在這，你在哪」的相互呼喚 |
| 警報叫（Alarm call）| 高頻、短促、急促重複 | 看到威脅 |
| 尖叫（Scream，特別是鸚鵡）| 極響、拉長、刺耳 | 索求注意、孤單、過度刺激、發情期 |
| 咬牙（Beak grinding） | 微弱節律 | 放鬆，準備休息 |
| 嘶聲 / 咆哮 | 噪音性、高 ZCR | 警告，不要靠近 |

### 重要提醒
- 鸚鵡黎明黃昏的「日出/日落叫」是正常生理行為
- 持續尖叫 = 飼主互動模式可能無意中強化了求注意行為
- 鳥羽毛蓬鬆 + 微弱叫聲 = 可能生病，鳥隱藏疾病很厲害

## 🦎 爬蟲類（守宮、蜥蜴、蛇）

### 一般原則

爬蟲類大多**不太發聲**，有聲音時通常代表壓力或防禦。

| 物種 | 主要聲音 | 含義 |
|------|---------|------|
| 豹紋守宮 | 吱吱短叫、嘶聲 | 受驚嚇、抗議被抓 |
| 鬃獅蜥 | 嘶聲、噴氣 | 威嚇、不滿 |
| 蛇類 | 嘶聲、噴氣、敲擊 | 威嚇警告 |
| 變色龍 | 通常無聲，可能咆哮 | 極度不滿 |

### 重要提醒
- 爬蟲類發出聲音 ≈ **「請停止讓我有壓力」**
- 不要把爬蟲類叫聲解讀為「想說話」，多半是要求停止當前互動
