# 音訊特徵 → 情緒推測對應（通則）

此檔提供「不分物種」的通用對應原則。任何叫聲都先用這份表格做第一輪推測，再用 `species_traits.md` 做物種校正。

## 核心原則：四個維度

動物聲音的情緒線索主要看四個維度：

1. **音高（Pitch）**：高頻 vs 低頻
2. **長度（Duration）**：短促 vs 拉長
3. **強度（Intensity / RMS）**：微弱 vs 響亮
4. **重複性（Onset count / Repetition）**：單次 vs 連續

## 通用對應表

### 音高高低

| 特徵 | 常見對應情緒 | 物種跨類別解釋 |
|------|------------|---------------|
| **高頻**（> 2000 Hz） | 警戒、求助、興奮、痛、幼體呼喚 | 高頻在演化上常見於「呼救／引起注意／警報」訊號 |
| **中頻**（500–2000 Hz） | 一般溝通、社交、需求表達 | 日常互動聲，情緒中性偏正面 |
| **低頻**（< 300 Hz） | 威脅、不滿、低吼、滿足（極少數情境，如貓咕嚕） | 低頻多用於「警告／佔有／距離威脅」 |

### 長度

| 特徵 | 常見對應情緒 |
|------|-------------|
| **極短**（< 0.3 秒）| 反射性、驚嚇、簡短呼喚 |
| **短促**（0.3–1 秒）| 一般呼喚、提醒、抱怨 |
| **中等**（1–3 秒）| 較強烈情緒表達 |
| **拉長**（> 3 秒）| 持續性需求（焦慮、疼痛、求偶、護地盤） |

### 強度

| 特徵 | 常見對應情緒 |
|------|-------------|
| **微弱** | 靠近時的低語、滿足、舒服、試探 |
| **中等** | 常態溝通 |
| **響亮** | 強烈情緒：警戒、驚嚇、攻擊前兆、極度需求 |

### 重複性

| 特徵 | 常見對應情緒 |
|------|-------------|
| **單次**（1 onset） | 單一事件反應（驚一下、招呼） |
| **重複數次**（2–4 onsets） | 確認性呼喚、抱怨、提醒（「喂？」「有人嗎？」） |
| **高密度**（5+ onsets，每秒 2+ 聲） | 緊迫、極度焦慮、警報模式 |

## 組合判讀（更可靠）

單一維度容易誤判，**兩個以上特徵交叉**才有較高信心。

### 高信心組合

| 組合 | 推測情緒 |
|------|---------|
| 高頻 + 短促 + 重複 + 響亮 | 警戒 / 求救 / 強烈不滿 |
| 高頻 + 拉長 + 微弱 + 單次 | 撒嬌 / 求關注 / 試探 |
| 低頻 + 拉長 + 響亮 + 重複 | 威脅 / 護資源 / 攻擊前兆 |
| 低頻 + 拉長 + 微弱 + 單次 | 滿足 / 放鬆（如貓咕嚕） |
| 中頻 + 中等長度 + 中等強度 + 單次 | 日常打招呼 / 一般溝通 |
| 高頻 + 短促 + 單次 + 響亮 | 驚嚇 / 突然疼痛 |
| 中頻 + 中等 + 中等 + 高密度重複 | 持續需求（餓、想出去、想玩） |

### 警訊組合（**必須在輸出中標註**）

| 組合 | 警訊類型 | 建議行動 |
|------|---------|---------|
| 低頻 + 拉長 + 重複 + 漸強 | 攻擊前兆 / 強烈不滿 | 不要靠近強迫互動，給空間 |
| 高頻 + 高密度重複 + 持續響亮 | 極度緊迫 / 痛苦 | 立即檢查環境與身體狀況 |
| 嗚咽（低頻 + 拉長 + 起伏 + 微弱）| 不適 / 疼痛 | 觀察是否就醫 |
| 嘶聲 / 高 ZCR + 低頻威嚇 | 強烈防禦狀態 | 移除壓力源，保持距離 |
| 持續性高音哀嚎 | 極度恐懼或痛苦 | 排除環境威脅，必要時就醫 |

## 信心度判定指引

| 信心度 | 條件 |
|--------|------|
| **High** | ≥ 3 個維度有明確訊號且互相印證；該物種有對應行為文獻 |
| **Medium** | 2 個維度有訊號或 3 個維度但物種對照偏弱 |
| **Low** | 音檔過短（< 0.5 秒）/ 雜訊多 / 物種叫聲行為學資料有限 / 特徵衝突 |

**衝突案例**：例如「低頻 + 微弱 + 單次」可能是滿足（貓咕嚕）也可能是不適初期，這時應標 Low confidence 並列出兩種可能。

## 物種無關的常見情境快速對照

使用者問題若提到下列關鍵字，可優先檢查對應特徵：

| 使用者問題關鍵字 | 優先檢查 |
|----------------|---------|
| 「為什麼一直叫」 | onset 是否高密度？是否有持續性需求模式？ |
| 「他在生氣嗎」 | 低頻 + 拉長 + 響亮？ZCR 高（嘶聲）？ |
| 「他不舒服嗎」 | 嗚咽模式（低頻 + 起伏 + 拉長 + 微弱）？單獨持續？ |
| 「他餓了嗎」 | 中頻 + 重複 + 中等強度？是否在固定時段？ |
| 「他想要什麼」 | 重複性如何？是否朝特定方向？看 onset count |
| 「他害怕嗎」 | 高頻 + 短促 + 單次驚嚇式？或縮在角落的微弱呼喚？ |
| 「他開心嗎」 | 中等強度 + 平穩或微起伏 + 不重複過密？|
